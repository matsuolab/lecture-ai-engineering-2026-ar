# نتائج مرجعية لـ Lecture 02 (أجراها المدرّس على T4)

إذا تعذر عليك الحصول على GPU أو إنهاء التدريب في الوقت المتاح، فاتبع القسم **4b** من دفتر الملاحظات (`notebooks/lora_format_tuning.ipynb`) واستخدم هذه النتائج للمقارنة والمناقشة.
عند التسليم، اضبط `executed_training_myself` في القسم 7 على `False`، واذكر في `lectures/02/answer.md` إلى أي مرحلة وصلت بنفسك في دفتر الملاحظات.

القياسات والمخرجات المرجعية المذكورة مأخوذة من التشغيل الياباني الأصلي؛ لم تُعَد هذه القياسات بالعربية.

| الملف | المحتوى |
|---|---|
| `result.json` | الإعدادات (`config`)، وإصدارات المكتبات، وملخصات ما قبل التدريب وما بعده (`before` / `after`)، والأسئلة التي تراجع أداؤها، ونتائج أسئلة المعرفة |
| `eval_before.json` | المخرجات الأصلية ودرجات الأسئلة الـ 21 قبل التدريب |
| `eval_after.json` | المخرجات الأصلية ودرجات الأسئلة الـ 21 بعد التدريب |

- افتح الملفات على GitHub أو احفظها باستخدام "Download raw file"
- تدريب GPU ليس قابلًا للتكرار تمامًا حتى مع قيمة البذرة نفسها؛ لذلك من الطبيعي أن تختلف «الأسئلة المتبقية» لديك. قارن أنواع الإخفاقات
